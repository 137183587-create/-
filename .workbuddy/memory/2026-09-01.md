## 修复 hash 跳转定位不准（首次到首屏、后续到中间）
- 问题：
  - 从首页首次点击「插画」导航，跳转到的是 `/medical-visualization` 首屏（Hero），而不是「公众号科普条漫」区块开头。
  - 刷新后再点「插画」，位置偏到 03 条漫（中间位置）。
- 根因：
  - 目标页面首次挂载时，`#comics` / `#motion` 元素尚未渲染，`ScrollManager` 立即 fallback 到 `window.scrollTo(0,0)`。
  - 后续跳转时，轮播/图片懒加载完成后布局位置发生变化，但只滚动一次，导致最终位置偏移。
- 改造：
  - `ScrollManager.jsx`：
    - 找不到锚点元素时，5 秒内每 100ms 重试，直到元素出现（避免首次挂载 fallback 到首屏）。
    - 命中元素后先滚动一次，再延迟 320ms 重新对齐一次，等轮播初始化/图片懒加载布局稳定。
  - `global.css`：给 `#motion`、`#comics` 等所有锚点 section 加 `scroll-margin-top: 90px`，作为 CSS 兜底。
  - `ComicsList.jsx`：将第 1 条漫封面图 `loading` 设为 `eager`，让首屏条漫布局更早稳定。
- 结果：从首页、导航、直接 URL 进入 `#comics` / `#motion`，都能准确滚动到区块开头并避让导航栏。
- 构建通过，预览 `http://localhost:5174/`、`http://localhost:5174/illustrations`、`http://localhost:5174/ai-motion`。
